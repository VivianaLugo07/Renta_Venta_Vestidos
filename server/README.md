## Descripción del proyecto
<h4 align="center">
Web app de gestión integral para locales de renta y venta de vestidos. 
Permite administrar de forma centralizada el inventario, los pedidos, las  reservas por fecha y los usuarios, evitando olvidos y dobles reservas, con un apartado de alertas sobre prendas sin devolver.
</h4>
